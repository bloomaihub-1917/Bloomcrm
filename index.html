기업 섹터 관리
메인 섹터와 서브섹터를 정의합니다. 기업에 복수 섹터를 적용할 수 있어요. 행사를 선택하면 그 행사만의 독립된 섹터 트리를 만들고 관리할 수 있어요(예: 바이오코리아 전용 메인/서브 섹터).
섹터 트리 대상
섹터 트리
서브섹터 칩을 드래그해서 다른 메인 섹터로 옮기거나, 맨 위 점선 영역에 놓으면 메인 섹터로 승격됩니다. "시트 보기 좋게 정렬"을 누르면 구글시트의 sectors 탭 행 순서를 메인 → 그 서브섹터들 순으로 재배열해요.

섹터명
📊 엑셀로 섹터 일괄 추가
"메인섹터" / "서브섹터" 2개 컬럼으로 된 엑셀(.xlsx)을 올리면, 지금 위에서 선택한 대상(공통 또는 특정 행사)에 메인·서브 섹터를 한 번에 만들어줘요. 이미 있는 섹터는 건너뜁니다.
🗂 미등록 섹터 그룹으로 묶기
업로드 데이터에 나온 섹터 값(예: Pharma, CRO, Vaccine)이 아직 섹터 체계에 등록 안 돼서 대시보드에 각각 따로 나올 때, 여기서 골라 하나의 그룹(메인 섹터) 아래로 묶을 수 있어요.
묶을 그룹(메인 섹터)
🏷️ 기존 메인 섹터를 그룹의 서브로 편입
이미 메인 섹터로 등록된 것들(예: Professional Services and Consulting, Synthetic drugs)을 골라 다른 메인 섹터(또는 새로 만드는 그룹, 예: BIO) 아래 서브섹터로 한 번에 옮깁니다. 선택한 섹터에 이미 서브섹터가 있으면 그 서브섹터도 함께 그룹 하위로 옮겨져요.

// 컨택 상태 변경 시 자동 알림
function onStatusChange(row, newStatus) {
  if (newStatus === '확정') {
    MailApp.sendEmail({
      to: 'manager@company.com',
      subject: `[CRM] ${row.name} 확정`,
      body: `담당자: ${row.assignee}`
    });
  }
}
