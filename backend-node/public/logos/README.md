# 웹디렉토리 로고 폴더

웹디렉토리(`/d/<행사슬러그>`)가 기업명 옆에 띄우는 로고를 둔다.

```
public/logos/<행사슬러그>/<도록순번>.<확장자>

  public/logos/2026-kic/1.png      → 순번 1번(SeltaSquare) 카드에 뜬다
  public/logos/2026-kic/44.png     → 순번 44번
```

파일을 넣으면 코드를 고치지 않아도 뜬다(최대 5분 뒤 — 폴더 목록을 그만큼
재사용한다). 파일이 없는 기업은 자리를 비우지 않고 아예 넣지 않는다. 빈 사각형이
늘어선 화면은 "아직 안 받았다"를 관람객에게 보여주는 것과 같다.

## 그래픽팀에 부탁할 규격

| 항목 | 규격 |
| --- | --- |
| 형식 | PNG (SVG·WebP·JPG도 받는다) |
| 배경 | 투명 |
| 높이 | 200px 이상 |
| 여백 | 로고 바깥 여백은 잘라낸다 |
| 파일명 | 도록 순번만 (`1.png`, `2.png` …) |

화면에서는 높이를 맞춰(일반 24px, 스폰서 34px) 줄이므로 폭은 제한하지 않는다 —
가로형 로고가 많아 폭을 고정하면 찌그러진다.

여백을 남기면 로고마다 실제 크기가 달라 보인다. 나란히 놓았을 때 어떤 건 작고
어떤 건 크게 보이는 원인이 대개 이것이다.

## 원본은 왜 그대로 못 쓰나

OneDrive 로고 폴더(`300. 전시/Logo`)에는 `.ai` 41개, `.eps` 4개, `.zip` 4개가
섞여 있다. 브라우저는 `.ai`도 `.eps`도 읽지 못한다 — `<img src="logo.ai">`는
빈 칸이 된다. 그래서 웹용으로 내린 파일을 여기에 따로 둔다.

`.ai` 41개는 전부 PDF 호환으로 저장돼 있어(파일 앞 4바이트가 `%PDF`) 도구로
자동 변환할 수도 있다. 지금은 그래픽팀이 Illustrator에서 직접 내리기로 했다 —
여백과 색을 사람이 보고 맞추는 편이 결과가 낫다.

## 이 폴더는 저장소에 커밋된다

저장소가 public이므로 넣는 파일도 공개된다. 기업 로고는 프로그램북과 웹디렉토리에
이미 공개되는 자료라 문제되지 않지만, 로고 외의 파일(제안서·도면·계약서)은 절대
여기에 두지 않는다.
