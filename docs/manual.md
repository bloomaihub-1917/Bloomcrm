## 0. 한눈에

Bloom CRM은 **사람(연락처)과 기업을 한 곳에 모아 두고, 행사마다 꺼내 쓰는** 도구다.

```
         ┌── 기업DB (회사)
DB(사람) ─┤
         └── 행사 참여 기록 ── 행사 · 전시 · 연사 · 파트너링
                    │
                    └── 컨택 (영업: TM·DM 차수) ── 행사별 영업 DB
```

- **사람은 한 번만 넣는다.** 같은 사람이 여러 행사에 오면 참여 기록만 늘어난다.
- **행사에서 무엇이었는지**(연사·전시참가기업·셀러·바이어 …)는 사람이 아니라 **행사 참여 기록**에 붙는다.
- **출처**는 사람마다 하나이고 바뀌지 않는다. 반면 **영업 DB**는 행사마다 켜고 끈다. 자세한 내용은 [manual-db-axes.md](manual-db-axes.md)에 있다.

### 로그인

- **@13100m.net** 계정을 가진 팀원만 들어온다.
- 권한 등급은 없고, 모두 같은 화면을 본다.
- 누가 무엇을 바꿨는지는 **활동 기록**에 남는다(10장).

### 화면 구성

| 메뉴 | 하는 일 |
|---|---|
| **DB** | 모든 사람(연락처) — Master DB |
| **기업DB** | 회사 정보와 회사별 행사 이력 |
| **컨택** | TM·DM 차수별 영업, 결과 기록과 보고 |
| **전시** | 참가기업의 신청 → 부스·비품·그래픽 → 정산 → 현장 |
| **연사** | 섭외 → 자료 → 프로그램 편성 → 연사료 정산 |
| **파트너링** | 셀러·바이어 참가자 |
| **행사** | 행사 하나의 개요·참가자·등록 링크 |
| 오른쪽 위 이름 | **설정**, **활동 기록** |

- 사이드바는 «‹ / ›» 버튼으로 접고 편다.
- 모바일 아래쪽 탭에는 DB·기업·컨택·전시·행사만 있다.
- 검색창은 화면마다 따로 있다. 화면 전체를 한 번에 찾는 통합 검색은 없다.
- 제목 줄의 **«추가»**(빠른 추가)는 지금 화면에 맞는 것을 바로 넣는다.
  - 행사·파트너링 화면에서는 사람을 찾아 참가 유형을 정한다.
  - 연사 화면에서는 이름·소속·직함만 넣는다.

## 1. DB — 사람(연락처)

### 찾기·거르기

- **검색**: 이름·기업·국가·이메일·전화번호로 찾는다.
  - «찾기»(AI)를 쓰면 «해외 바이오 대표급»처럼 문장으로 물을 수 있다. 질문을 지우려면 «✕ 질문 지우기»를 누른다.
- **목록 위 거르개 줄**: 행사 · 유형 · 출처 · 영업 DB
  - **행사**: 그 행사에 참여한 사람만 보인다.
  - **유형**: 참가 유형(연사·전시참가기업·셀러 …)으로 거른다.
  - **출처**: 수주 행사 참가자 · 타 행사 · DB 취합 · 미정(아직 안 정함)
  - **영업 DB**: 행사를 누르면 그 행사의 영업 대상만 보인다.
  - 같은 칩을 다시 누르면 풀린다.
- **사이드바**: 분야, 지역(국내·해외·나라), 태그(BD 등), «퇴사 포함»

### 여러 명 한꺼번에

- 이름 앞 동그라미를 눌러 사람을 고른다. **Shift**를 누른 채 누르면 그 사이 사람이 모두 골라진다.
- 고르면 위에 일괄 작업 바가 뜬다.

| 버튼 | 하는 일 |
|---|---|
| «행사에 초청» | 고른 사람을 행사 참가자로 넣는다 |
| «컨택으로 보내기» | 고른 사람의 기업을 컨택 차수 명단에 넣고, **고른 사람만** 그 행사의 영업 DB로 켠다 |
| «선택 삭제» | 연락처와 그 사람의 행사 참여 기록·영업 DB 표시를 함께 지운다. 화면에서 되돌릴 수 없으니 조심한다(활동 기록에서 되살리기는 가능) |

### 연락처 추가

- 사이드바 또는 모바일의 «＋»로 연다.
- 이름·소속·직함·메일·전화·국가를 넣는다.
- **출처**를 고른다. 사람마다 하나이고 나중에 바뀌지 않는다.
- «들어온 경로»는 «명함», «행사 등록»처럼 적는 메모다.
- 소속이 기업DB에 없으면 새 기업이 만들어진다. 이때 **소속 기업 분류**(분야·섹터)를 같이 정해 두면 나중에 미분류로 떨어지지 않는다.

### 연락처 상세 (이름을 누르면 오른쪽에 열림)

- **기본 정보**: 이름·소속·직함·부서, 메일·전화 2개씩, 국가, 언어, 상태, 태그, 메모. 고친 뒤 «저장».
- **출처 · 행사별 영업 DB**
  - 출처를 고친다.
  - 행사 이름을 눌러 그 행사의 영업 DB를 켜고 끈다.
- **컨택**
  - 이 사람의 기업이 들어간 차수 목록이 보인다.
  - «+ 컨택에 넣기», «빼기»를 쓴다.
- **참여 행사**: 행사별 참가 유형을 보고, «참여 행사 추가»로 더한다.
- **주고받은 메일**: 행사 메일함에서 자동으로 모은 메일이다.
- **🏢 기업명 / «기업정보»**
  - 회사 요약 창이 뜬다(종류·섹터·연락처·소개·참여 행사·컨택 차수·재직 담당자).
  - «기업DB에서 열기 · 고치기»로 기업DB로 간다.
- **퇴사 처리**
  - 퇴사 확인일을 남긴다.
  - 퇴사자는 목록에서 기본으로 숨는다(«퇴사 포함»을 켜면 보인다).

> **연락처 id 규칙(개발 참고)**: 새 id는 화면 `nextContactId()`에서 받는다. 스크립트로 넣을 때는 `contactIdAllocator()`를 쓴다. 16자리를 넘으면 사람이 뭉개진다. 자세한 내용은 CLAUDE.md.

## 2. 기업DB — 회사

- **목록**: 기업명·국문명·영문명 순으로 정렬하고, 검색과 AI «찾기»를 쓴다.
- **«+ 기업 추가»**: 이름과 종류(잠재고객사·벤더시공사·유관기관·전시참가기업)를 넣고 «등록».
- **기업 상세**
  - 약어·국가·주소·대표 전화·메일·웹사이트·회사소개·취급 품목·메모를 적는다.
  - **«📄 소개서 PDF로 채우기»**: AI가 소개서를 읽어 회사소개를 요약해 넣는다. 이미 소개가 있으면 바꿀지 먼저 묻는다.
  - **«+ 참여 이력 추가»**, «전시에서 열기»
  - **«컨택 명단에 넣기»**: 기업을 차수에 넣으면 그 기업의 **재직 담당자 모두**가 그 행사의 영업 DB로 켜진다.
- **비슷한 이름 합치기**
  - 비슷한 이름의 기업이 보이면 병합을 제안한다.
  - 같은 회사가 아니면 «다른 기업임»을 누른다. 다시 제안하지 않는다.
  - 합칠 때는 딸린 연락처 수를 보여 주고 확인을 받는다.

## 3. 컨택 — 영업(TM·DM)

행사마다 **차수**(1차 TM, 2차 DM …)를 만들고, 차수마다 연락할 **기업 명단**을 둔다.

### 차수와 명단

- **«+ 차수 만들기»**: 행사, 방식(TM/DM), 이름, 목표를 정한다.
- **«명단 채우기»**
  - «행사 참가 기록에서»: 지난 행사 참가 기업을 가져온다.
  - «분야로»: 기업 분야로 고른다.
  - «엑셀 기록 가져오기»: 손으로 정리해 둔 컨택 엑셀을 가져온다.
- 다른 곳에서 넣기: DB의 «컨택으로 보내기», 기업DB의 «컨택 명단에 넣기», 파트너링의 «컨택으로 보내기».
- **«명단 빼기»**: 여러 곳을 골라 한 번에 뺀다.
  - 연락 기록이 있는 곳은 기록을 지우지 않도록 **«종료»로 닫힌다**.
  - 컨택에서 빼도 **영업 DB 표시는 그대로**다.

### 오늘 할 컨택

- 위쪽 칸: 지금 할 곳 · 걸 차례 · 다시 걸 차례 · 기다림 · 끝남 · 목표 달성
- 카드마다 결과를 누른다: **긍정 · 보류 · 부정 · 부재중 · 번호 오류**, 그리고 메모.
- **«다음 연락»** 날짜를 정하면 그날 다시 올라온다. 마감 대신 리마인더로 쫓는다.
- «✉ 이 기업에 메일»: 행사 메일함으로 바로 보낸다.

### 현황표 · 보고

- **현황표**: 기업 × 차수 표다. «엑셀로 내려받기».
- **보고**
  - 숫자 카드: 진행 · 이번 주 · 연락한 곳 · 목표 달성
  - **일일보고** 문장이 자동으로 만들어진다. «문장 복사» 후 메신저에 붙인다.
  - 명단별, 차수별 표

### 협의 보드 · 협의 목록

- 이름이 실린 협의 대상을 단계별로 쫓는다: **미접촉 → 컨택중 → 협의중 → 확정**.
- «+ 추가»: 기업명, 담당자, 초기 접근 전략을 적는다.
- «+ 메모», «원문 보기», «이력에 넣기»

### 여러 곳에 메일

- «✉ 메일 보내기»로 연다.
- 받는 곳 고르기: «보낼 차례만 / 미연결만 / 전체»
- 문구는 «양식 보관함»에서 불러온다.

## 4. 전시 — 참가기업 운영

위쪽에서 행사를 고른 뒤 탭을 연다.

| 탭 | 내용 |
|---|---|
| **대시보드** | 단계별 진행, 정산 현황, 메일함, **처리 필요**(인보이스·입금 리마인더). «마감일 설정», «✉ 여러 기업에 메일», «엑셀 다운로드» |
| **기업리스트** | 참가기업 표. 진행 칩(예: «입금 48/51»)을 누르면 그 단계가 남은 곳만 보인다. «참가기업 추가 / 불러오기», «✉ 부스 변경 안내 보내기» |
| **부스 현황** | 부스 번호·타입·시공사. «시공사 입력», «부스 비치용 출력» |
| **비품 현황** | 기업별 렌탈 비품. «+ 품목 추가», «렌탈업체용 다운로드», «엑셀 내보내기»([대장 형식](data-export.md)) |
| **그래픽 현황** | 초안 → 수정안 → 최종안 → 출력. «+ 그래픽 주문 추가», «마감 일괄 지정» |
| **금액 현황** | KRW·USD별 부스·비품·그래픽 청구액과 입금액 |
| **프로그램북** | 기업 소개 게재 순서. «순서 자동 매기기», «웹디렉토리 열기»([웹디렉토리](web-directory.md)) |
| **현장 처리** | 현장 반입·설치·출입증 확인(«✓ 현장») |
| **파일 감시** | 공유 폴더를 훑어 기업별로 새로 들어온 파일을 알려 준다. «폴더 추가», «전부 다시 훑기», «모두 확인» |

### 참가기업 상세 (기업명을 누름)

- **기본 · 담당자**
  - 담당자를 «메인으로» 지정한다.
  - «마스터DB로 올리기»로 DB 사람과 잇는다.
- **진행**
  - 신청서 수신, 매뉴얼 발송·회신, 도면 수령·확인, 부스 확정, 반입·설치, 출입증 날짜를 찍는다.
  - «저장 폴더 지정»으로 이 기업의 파일 폴더를 정한다.
- **부스 · 그래픽**: 시공사와 기업 담당자 중 연락할 상대를 정하고, 그래픽 단계를 진행한다.
- **신청항목**
  - 신청서를 받을 때마다 무엇이 달라졌는지 이력이 남는다([신청서 접수 이력](apply-tracking.md)).
  - «인보이스 발행»은 인보이스 줄 만들기, 양식 채우기, 폴더 저장을 한 번에 한다([인보이스](invoice-export.md)).
- **정산**
  - 청구 줄과 입금 기록을 남긴다.
  - «완납으로 닫기», «위약금으로 남김»
  - 초과 입금과 금액 미입력은 따로 표시된다.
- **프로그램북**: 게재 소개글과 사진
- **메일함 · 문의·기록**
  - 이 기업과 주고받은 메일과 문의를 본다. «답변 완료».
  - **«✉ 리마인더 초안»**: 아직 안 된 것을 짚는 메일을 만든다.
  - **«+3일 / +1주»**: 다음 알림을 미룬다.

### 여러 기업에 메일

- 받는 곳 고르기: «보낼 차례만 / 사진 있는 곳만 / 전체»
- «◀ ▶»로 기업마다 들어갈 내용을 미리 본다.
- **«나에게 먼저 1통»**으로 시험 발송한 뒤 보낸다.
- 문구는 «📚 양식 보관함»에 저장해 두고 다시 쓴다.

> 행사가 «진행 완료»면 위에 초록 안내 줄이 뜬다. 지난 기록은 볼 수 있다.

## 5. 연사 — 컨퍼런스 운영

| 탭 | 내용 |
|---|---|
| **대시보드** | 연사 수 · 참가 확정 · 자료 진행 · 처리 필요(리마인더 보낼 때 등), 연락 단계 막대, 메일함 |
| **Program at a Glance** | 세션 시간표. «양식 받기 → 엑셀 올리기», «표 복사» |
| **Program** | 세션 만들기, 연사 배정·해제, 시간 배분. «✉ 일정 변경 안내 보내기». 패널토론은 같은 시간에 여럿이 앉으므로 «겹침» 경고를 띄우지 않는다 |
| **Speakers** | 연사 표·카드. 아래 표 참고 |
| **파일 감시** | 연사 자료 폴더를 훑는다 |

**Speakers 탭**

- **준비 / 정산** 두 가지 보기가 있다.
- **준비**
  - 자료 칩(소속·직함, 이력, 사진, 발제명 …)으로 누가 냈고 누가 안 냈는지 본다.
  - «받음», «한꺼번에 받음»
- **정산**
  - 연사료·서류·지급을 본다.
  - «💰 지급대장 다운로드», «🏦 대량이체 파일»
  - 연사료가 없는 사람은 맨 아래에 접혀 있다.
- **«🔗 외부 공유»**: 주최 측에 연사 현황 링크를 준다.
  - «새 링크로 바꾸기»를 누르면 옛 링크가 막힌다.
- **«📨 여러 연사에게 메일»**: 보낼 차례인 사람을 고르고, «✨ AI로 초안 쓰기», «나에게 먼저 1통»으로 시험 발송.

**연사 상세**

- **단계 줄**: 자료 받기 → 발표 → … «확인됨 — 받은 날 찍기», «↶ 이전 단계로».
- **마스터DB 연결**
  - «연락처에서 끌어오기», «마스터DB에 새로 등록», «연결 끊기»
  - 연결해 두면 DB에서 그 사람의 연사 이력이 보인다.
- «지난 자료 가져오기»: 다른 행사에서 받은 이력·사진을 다시 쓴다.
- **계좌·여권**: 기본으로 가려져 있고, «전체 보기»를 눌러야 보인다.
- 끝난 컨퍼런스는 열람만 된다.

---

## 6. 파트너링 — 셀러·바이어

- 탭: **참가자 명단 · 확정 대기 · 셀러·바이어 지정 · DB에서 찾아 넣기**
- «+ DB에서 찾아 넣기»로 DB 사람을 참가자로 넣고 «참가 확정».
- «컨택으로 보내기»: 모집 영업 명단으로 넘긴다. 그 행사의 영업 DB도 켜진다.

---

## 7. 행사 — 한 행사의 명단

- 탭: **개요 · 참가자 · 협의 대상 · 전시기업 · 연사 · 파트너링**
- **참가자**
  - 사람별/기업별로 본다.
  - «참가 확정 / 확정 해제», «메일 대상 모으기», «주소 복사»
  - **«📤 명단 업로드»**: 데이터 업로드 화면이 열리고 «연결 행사»가 이 행사로 맞춰져 있다(8장).
- **«🔗 등록 링크»**
  - 온라인 신청 링크를 만든다.
  - 신청자는 «확정 / 모두 확정 / 버리기»로 처리한다.
  - 엑셀 양식으로 한꺼번에 올릴 수도 있다.

---

## 8. 데이터 업로드 — 엑셀 명단 넣기

설정 › **📤 데이터 업로드**. 또는 행사 › 참가자 › «📤 명단 업로드».

1. 엑셀을 올린다.
2. **출처**를 고른다.
   - 행사 참가자로 올리는 명단은 «수주 행사 참가자».
   - 모아 둔 명단을 한꺼번에 올리면 «DB 취합».
   - 다른 행사의 참가자 데이터는 «타 행사».
   - 출처는 새로 들어오는 사람에게만 적힌다.
3. **연결 행사**를 고르면 올린 사람이 그 행사 참가자로 걸린다. 고르지 않으면 DB에만 들어간다.
4. **열 맞추기**: 엑셀 열을 이름·소속·메일 등에 잇는다.
   - «✨ AI로 남은 열 맞추기»를 쓸 수 있다.
   - 전에 쓴 매핑은 다시 적용된다.
5. 기업DB에 없는 회사는 새 기업으로 만들거나 기존 기업에 붙인다.
6. **겹침 거르기**: 메일·이름+소속이 같은 사람은 새로 만들지 않는다. 애매한 것은 **로그 › 병합**에서 «병합 승인 / 별도 유지»로 정한다.

## 9. 설정

| 탭 | 내용 |
|---|---|
| **📅 행사 관리** | 행사 추가(코드·이름·장소·색). 행사마다 진행 파트(전시·연사·파트너링), 단계 편집, **메일**(행사 공용 메일함 계정, «주최사 메일 도메인»), 컨퍼런스 날짜 |
| **🏭 기업 분류** | 분야(큰 갈래) → 섹터. 추가, 서브로 넣기, 병합 |
| **👤 사람 분류** | 참가 유형(VIP·연사·셀러 …), 태그(BD 등) |
| **📋 공통 목록** | 화면 곳곳의 선택지 목록 |
| **🪑 비품 목록** | 행사별 렌탈 비품 카탈로그([비품 카탈로그](equip-catalog.md)) |
| **🧹 데이터 정리** | 국가명 일괄 정리, 기업명 분리, 비슷한 기업명 찾기, AI로 기업 정보 추천 받기 |
| **✨ AI 설정** | AI 기능 문구·기본값 |
| **⚙️ 시스템 정보** | 연결 상태 |

### 메일 설정에서 알아 둘 것

- 메일은 **행사별 공용 메일함**(메일플러그·Gmail·네이버 웍스)으로 보낸다. 메일함이 없는 행사는 메일을 보낼 수 없다. 대신 다른 계정으로 보내 주는 기능은 없다.
- 보낸메일함·받은메일함은 자동으로 모여 기업·연사의 «메일함»에 붙는다.
- **«주최사 메일 도메인»**에 주최 측 도메인(예: KIC는 `konect.or.kr`)을 적어 둔다. 그래야 주최 측이 참조로 들어간 메일이 엉뚱한 기업에 몰려 붙지 않는다.
- AI 기능에는 메일 본문과 개인정보를 보내지 않는다. 업체 소개서 PDF 요약만 예외다.

## 10. 활동 기록 · 되돌리기

- 오른쪽 위 이름 › **활동 기록**
- 거르기: 전시 · 연사 · CRM · 연락처·기업 · 설정 · 삭제 · 로그인
- **«되돌리기»**
  - 고친 것은 이전 값으로 돌린다.
  - 지운 것은 되살린다.
  - 새로 만든 것은 지운다.
  - 되돌린 일도 기록에 남는다.

## 자주 묻는 것

- **같은 사람이 두 번 있어요.** 업로드 › 로그 › 병합에서 합친다. 기업은 기업DB의 병합 제안을 쓴다.
- **연락 기록에 엉뚱한 회사 메일이 보여요.** 그 회사 담당자 칸에 공용 주소(info@ 같은 것)가 잘못 들어가 있는지 본다. 그리고 행사 설정의 «주최사 메일 도메인»을 채운다.
- **컨택에서 뺐는데 영업 DB에 남아요.** 정상이다. 끄려면 연락처 상세 «출처 · 행사별 영업 DB»에서 행사 이름을 다시 누른다.
- **잘못 지웠어요.** 활동 기록 › 삭제에서 «되돌리기».
