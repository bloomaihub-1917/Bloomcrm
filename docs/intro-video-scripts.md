# Bloom CRM 소개 영상 — 장면별 대본 (3편)

- 길이: 편당 60~80초 / 화면 1920×1080
- 표기: **[화면]** 보여줄 곳 · **[동작]** 클릭·입력 · **[자막]** 화면 아래 한 줄 · **[효과]** 확대·강조
- 장면 순서는 2026-10-27에 실제 화면을 캡처해 맞췄다 (`docs/storyboard/`).
  ✅ = 캡처로 확인한 화면, ☐ = 아직 화면을 확인하지 못한 장면(녹화 전에 열어 보고 넣거나 뺀다)
- 녹화는 테스트 데이터로 한다 — 실제 운영 계정으로 찍으면 연사·기업 실명이 나온다

---

## 공통 오프닝 (0:00–0:05)
- [화면] 왼쪽 위 아이콘 줄 DB·기업DB·컨택·전시·연사·행사
- [동작] 이번 편의 아이콘에 마우스를 올린다
- [효과] 그 아이콘만 밝게, 나머지 흐리게
- [자막] «행사 하나의 사람·기업·메일을 한 곳에서 — Bloom CRM»

## 공통 엔딩 (마지막 5–8초)
- [화면] DB 탭 → 연락처 한 명 → «주고받은 메일» ☐
- [자막] «행사가 끝나도 기록은 사람에게 남습니다»
- [효과] 로고 + «다음 편: ○○»

## 녹화 전 체크리스트
- ☐ 테스트 데이터로 로그인 (실명·실메일·실전화 0건)
- ☐ ☐ 표시한 장면을 실제 화면에서 열어 보고 넣거나 뺀다
- ☐ 브라우저 1920×1080, 확대 100%, 알림·북마크바 숨김
- ☐ 메일·DM은 **실제로 보내지 않는다** — 보내기 직전에서 컷
- ☐ BGM 하나로 세 편 통일, 자막 글꼴 Pretendard
