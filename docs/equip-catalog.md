# 렌탈 비품 카탈로그

참가기업이 신청하는 렌탈 가구·가전의 품목표다. 행사마다 렌탈사와 단가가 바뀌므로
**행사별로 따로** 관리한다.

## 왜 카탈로그를 두는가

전에는 비품 이름을 손으로 적어 넣었다. 그래서 같은 의자가 이렇게 들어왔다.

```
C-040 Folding Chair
C-040 - 접이식 체어
접이식 체어
```

발주할 때 품목별 합계가 셋으로 갈라지고, 단가는 매번 엑셀에서 다시 찾아야 했다.
카탈로그를 두고 거기서 고르면 이름이 어떻게 적히든 **같은 품목으로 묶인다**.
실제로 2026 KIC 신청 내역이 66종에서 41종으로 합쳐졌다.

## 구조

```
equip_catalog
  id          EC-0005-2026KIC      행사 이름을 붙여 행사별로 겹치지 않게
  event_id    2026 KIC             어느 행사의 품목표인가
  category    의자 | 테이블 | 진열대 | 가전제품 | 기타비품
  code        C-040                행사 안에서만 유일 (같은 코드가 행사마다 다른 가격일 수 있다)
  name_ko     접이식 체어
  name_en     Folding Chair
  spec        500*420*750mmH
  price_krw   11000
  price_usd   11
  active      'no'이면 목록에서 숨김 (지우지 않는다 — 아래 참고)
  sort_order

exhibitor_items.catalog_id → equip_catalog.id
```

**단종 품목을 지우지 않는 이유**: 이미 그 품목을 신청한 기업의 주문이 무엇을
가리키는지 알 수 없게 된다. 목록에서만 내린다(`active='no'`).

**행사별로 나누는 이유**: 단가를 덮어쓰면 지난 행사의 정산 근거가 조용히 바뀐다.
행사가 끝나도 그때 단가가 그대로 남아 있어야 한다.

## 새 행사 준비

### 1) 지난 행사에서 복제

```bash
node db/clone-equip-catalog.js --from "2026 KIC" --to "2027 KIC"
```

단가가 일괄로 오르면 `--rate`를 준다 (5% 인상, 원 단위 반올림):

```bash
node db/clone-equip-catalog.js --from "2026 KIC" --to "2027 KIC" --rate 1.05
```

이미 만들어 둔 품목은 건너뛴다 — 새 행사에서 손본 단가를 되돌리지 않는다.

### 2) 또는 엑셀에서 새로 넣기

렌탈사가 바뀌어 품목 자체가 달라지면 카탈로그 엑셀을 그대로 넣는다.

```bash
node db/import-equip-catalog.js --event "2027 KIC" --file "경로/카탈로그.xlsx"
```

엑셀은 **[품목마스터]** 시트를 읽고, 열 이름이 아래와 같아야 한다.

| No | 카테고리 | 코드 | 품명(국문) | 품명(영문) | 규격(mm) | 이미지 | 단가(KRW) | 단가(USD) | 비고 |
|---|---|---|---|---|---|---|---|---|---|

- 코드가 같으면 덮어쓴다(가격 개정 시 그대로 다시 돌리면 된다).
- 이번 엑셀에 없는 품목은 지우지 않고 `active='no'`로 내린다.
- 여러 번 돌려도 안전하다. `--dry`로 미리 볼 수 있다.

### 3) 이미 들어온 신청을 카탈로그에 잇기

엑셀·메일로 먼저 받아 이름만 적힌 신청이 있으면 코드로 이어준다.

```bash
node db/link-equip-catalog.js --event "2027 KIC"
```

이름 어디에 있든 품목 코드(`C-040`, `T-043`, `E-099`)를 찾아 맞춘다.
**이름은 고치지 않는다** — 기업이 실제로 적어 보낸 문구라 그대로 남아야
나중에 무엇을 요청했는지 되짚을 수 있다. 연결만 채운다.

못 맞춘 항목은 목록으로 보여준다. 대개 카탈로그 밖의 품목(그래픽 랩핑, 전기 등)이다.

## 화면에서

- **전시 → 비품 현황**: 품목별 합계가 발주서에 쓰는 숫자 그대로 나온다.
  카탈로그에 없는 항목은 `카탈로그 외` 배지로 구분한다.
- **기업 드로어 → 정산 → 금액 항목**: 항목명 칸에서 카탈로그를 골라 넣으면
  단가와 분류가 함께 채워진다.

## 직접 입력한 품목은 자동으로 품목마스터에 올라간다

카탈로그에 없는 품목이 계속 들어온다(행사마다 새 품목, 렌탈사 추가 품목).
그때마다 이름만 적고 넘어가면 다음 기업이 같은 걸 신청할 때 또 손으로 적게 되고,
표기가 갈라져 발주 합계가 다시 흩어진다.

그래서 **분류가 `비품`인 항목을 직접 입력하면 그 행사 품목마스터에 함께 올린다.**

- 다음부터는 목록에서 골라 쓸 수 있고 단가도 따라온다.
- 같은 이름이 이미 있으면 새로 만들지 않고 그 품목에 잇는다 — 같은 의자가
  두 줄로 생기면 카탈로그를 둔 이유가 없어진다.
- 이름에 코드(`C-040`)가 들어 있으면 그 코드를 쓰고, 없으면 `X-001`부터
  직접 추가용 코드를 붙인다.
- `note`에 `직접 추가`를 남겨 정식 카탈로그와 구분한다. 비품 현황에서
  **직접 추가** 배지로 보인다 — 렌탈사 카탈로그를 다시 받을 때 이 품목들의
  단가·규격을 확인하면 된다.
- 분류가 비품이 아니면(부스·그래픽·기타) 올리지 않는다. 렌탈 가구 품목표이기
  때문이다.
